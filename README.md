I generally work through things from first principles. Right now that means writing a **software rasterizer by hand in C++** while gradually learning Vulkan and DirectX 12 — the point being to understand the work a GPU normally does for you automatically. On the systems side, I'll go low enough to read the assembly my C compiles to (though you'll never catch me writing Assembly by hand). Recently I started learning C#, both to keep a foot in the high-level world and to integrate it into larger low-level projects as a layer for readability and ease of use. My biggest inspiration on this path is Capcom's RE Engine — to me, a model of what computer graphics and software architecture should be.

### Currently building
- **Software rasterizer** — C++, rendering pipeline by hand, no engine. Next step: Vulkan / DirectX 12.
- **Gravity simulator** — C#, a minimalist gravity simulation for testing acceleration and collisions.
